# Karolens

**The Karoseri Project & Compliance Operating System**

Karolens mengendalikan perjalanan proyek karoseri—mulai dari spesifikasi dan kontrak pelanggan, kebutuhan material, estimasi biaya, jadwal produksi, kepatuhan teknis/legal, laporan dan penagihan, sampai serah terima dan garansi.

## Commercial baseline

- Target list price: **Rp1.120.000 per company per month** (one final customer-facing price; tax handled within the price for planning purposes).
- Internal target net receipts: Rp1.000.000 per company per month, subject to actual tax/accounting treatment. Validate with a tax professional before invoicing.
